&#x20;  # Security Policy



&#x20;  ## Reporting a Vulnerability

&#x20;  The RVA team takes security seriously. If you believe you have found a security vulnerability, please report it responsibly.



&#x20;  \*\*Please do NOT report security vulnerabilities through public GitHub issues.\*\*



&#x20;  ### How to Report

&#x20;  Please use GitHub's private vulnerability reporting feature or contact \[@richardeleanya](https://github.com/richardeleanya) directly.



&#x20;  ### Response Timeline

&#x20;  - \*\*Initial acknowledgment:\*\* Within 48 hours

&#x20;  - \*\*Triage and validation:\*\* Within 7 business days



&#x20;  ### Scope

&#x20;  \*\*In scope:\*\* Application code in `src/`, database migrations, CI/CD workflows, and tenant isolation mechanisms.

&#x20;  \*\*Out of scope:\*\* Third-party dependencies (report to upstream maintainers).
